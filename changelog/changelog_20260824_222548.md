# Books persistent memory — Phase 1

Implemented owner-isolated persistent Books conversations without deploying production changes.

- Added `ai_conversations` and `ai_messages`, deterministic ordering, idempotent request IDs, ownership immutability, indexes, constraints, and private owner-only RLS.
- Selected `public.users.id` as the owner foreign key; `auth.uid()` maps through `users.auth_user_id` / `public.app_user_id()`.
- Updated `ai-chat` to create/verify conversations, load authoritative persisted history, preserve tools, persist messages, and mark provider failures as retryable without fake assistant rows.
- Updated the widget/API to restore the selected or recent transcript, retain it across refresh/navigation/close, reconcile optimistic UUIDs, and clear state on sign-out/account change.
- Added focused memory, migration, service-role scoping, idempotency, restoration, and regression tests.
- Updated `BOOKS_MEMORY_DIAGNOSIS.md`, `docs/CHAT_WIDGET.md`, and `README.md`.

Deferred: conversation-history management UI, rolling summaries, embeddings, and cross-conversation memory.
