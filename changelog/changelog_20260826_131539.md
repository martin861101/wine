# AI chat resilience and retry hardening

Date: 2026-08-26

## Fixed

- Added structured, content-safe server diagnostics and correlation `errorId` values for failures after user-message persistence.
- Added a 20-second Gemini timeout, safe non-JSON handling, response-shape validation, provider request-ID capture, and typed mappings for network, timeout, rate-limit, authentication, rejected, and upstream 5xx failures.
- Reworked the four-round tool loop to log tool failures without arguments, pass only a generic tool error back to Gemini, and require a tool-free final summary after tool-call exhaustion.
- Persist safe failure stage/category, correlation ID, retryability, and retry count without storing stacks or upstream payloads.
- Made failed-message retries atomic and idempotent by reusing the same request/message row. Assistant insert races now return an existing completed response rather than overwriting it.
- Updated shared HTTP error handling to log the actual exception name, message, and stack server-side while retaining safe client responses.
