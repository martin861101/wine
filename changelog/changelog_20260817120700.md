# Changelog — 2026-08-17 12:07:00

## Isolated public local testing from production configuration

- Made local and HTTPS-public startup scripts use the Docker PostgreSQL database, console email, and local storage provider.
- Mapped Docker PostgreSQL to host port 55432 to avoid the existing service on port 5432.
- Made database startup wait for the PostgreSQL health check before running migrations.
- Updated `npm run pm2:restart` to apply the public ecosystem environment instead of only restarting the previous process definition.
- Added explicit local migration and seed commands so a production `.env` cannot redirect local tests to production services.
- Updated the PM2 public mode with the same isolated development services.
