# Books AI provider and research upgrade

Implemented and deployed on 24 August 2026.

## Changes

- Replaced the structured book provider with a shared Open Library adapter for normalized search, work/edition details, ISBNs, page counts, subjects, publication metadata, source URLs, and covers.
- Added Gemini-compatible `get_book_details`, `search_web`, and `read_webpage` declarations while preserving the existing Gemini request loop, authentication, 429 behavior, diagnostic logging, club tools, UI actions, audio, moods, effects, surprise flow, and server validation.
- Added Tavily behind the provider-independent `search_web` contract. Only normalized titles, URLs, snippets, and source hostnames are returned; the key remains server-side.
- Added a bounded webpage reader with HTTP(S)-only validation, DNS/IP checks, private-network blocking, redirect revalidation, standard-port restrictions, timeouts, response-size and content-type limits, HTML noise removal, and output truncation.
- Migrated the member search Edge Function and frontend invocation to `open-library-search` and updated normalized `SHOW_BOOK` payload validation.
- Migrated the legacy Node reference provider to Open Library and removed obsolete provider configuration, source, endpoint, environment, frontend, and current documentation references.
- Updated `README.md`, the Supabase guide, Books AI documentation, book-discovery documentation, and related implementation notes.
