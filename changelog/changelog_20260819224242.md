# Changelog — 2026-08-19 22:42:42 SAST

## Added

- Added `backend/scripts/deploy-supabase.sh` for guarded, repeatable Supabase backend
  deployments.
- Added root and backend `deploy:supabase` npm commands.
- The script validates the linked project and CLI authentication, runs backend checks,
  displays migration history, requests confirmation, applies pending migrations, pushes
  project/Auth configuration, deploys all Edge Functions, and verifies remote state.
- Added `--yes`, `--skip-checks`, `--skip-config`, and `--skip-functions` options.
- Documented interactive and CI usage in `README.md`.
